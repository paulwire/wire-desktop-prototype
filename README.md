# wire-desktop-prototype

A prototype desktop client for Wire built with [Compose Multiplatform](https://www.jetbrains.com/lp/compose-multiplatform/) and powered by [Kalium](https://github.com/wireapp/kalium), Wire's Kotlin Multiplatform SDK.

## About

This project explores building a native Wire desktop experience using Compose Multiplatform for the UI layer, sharing business logic and protocol handling with Kalium. It is an early-stage prototype, not a production client.

## Tech stack

- **Kotlin Multiplatform** — shared language and tooling across platforms
- **Compose Multiplatform** — declarative UI for desktop (JVM)
- **Kalium** — Wire's SDK for messaging, end-to-end encryption, and backend communication
- **Gradle** — build tooling

## Status

Early prototype / work in progress.
