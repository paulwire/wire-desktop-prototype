# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through GitHub's private vulnerability reporting feature rather than opening a public issue.

To submit a report:

1. Go to the [Security tab](../../security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in as much detail as you can, including steps to reproduce and potential impact.

Do not disclose the vulnerability publicly (e.g. via a public issue, pull request, or discussion) until it has been triaged and a fix has been released.
